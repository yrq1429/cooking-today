# 中文菜谱 API 核验（2026-10-23）

本次仅核查在线接口，不导入或扩充小程序本地菜谱，不改动日记数据。

## 悦耳数据：标价免费，需要密钥

- 文档：https://api.ip13.com/doc/65
- 注册：https://api.ip13.com/user/register
- 密钥管理：https://api.ip13.com/user/key
- 查询：GET https://api.ip13.com/api/recipes/searchrecipes
- 参数：key、cookbook_name、limit（可选）。密钥应保管在服务端。
- 当前官网标价「免费」，页面同时显示「免费额度：无」，请求限制写每日不限、总频率30QPS。字段表述存在歧义，注册后应以账户实际可用权益为准，不能据此承诺永久免费不限量。
- 先前无密钥实测：HTTP 200、业务 code=403。现已使用用户提供的密钥完成认证与查询验证，业务 code=200；密钥不写入本文或核验结果。
- 官方文档公开样例是两份红烧肉：分别6步、5步，均含食材清单与逐步图片URL。两份样例共11张步骤图均实际请求成功（HTTP 200、200×200），成品图也能打开。已目视检查，为原料处理及成菜照片。
- 已认证实测：10个常见菜名查询全部成功，各取3条，共30份菜谱；219个步骤、210个步骤图片地址，27份菜谱每一步都有图片地址。
- 实际访问其中28张图片，28/28成功，全部HTTPS、200×200。因此图文数据可用，但图片清晰度仍偏低。
- 部分返回质量不合格：一份麻婆豆腐仅列1项食材，一份酸辣土豆丝仅2个步骤；3份菜谱存在缺步骤图的情况。接入时需要过滤缺食材、过度简略或缺图内容，不能原样展示所有结果。
- 查询耗时约1.4～2.7秒。应用应明确显示加载状态并处理慢请求。
- 核验结果见同目录 ip13-live-validation.json。本次没有把API响应导入前端本地菜谱库，现已将首页、搜索和详情接到服务端代理，浏览器预览完成真实图文联调；微信正式云函数尚未部署。

## UAPI：免密钥测试已跑通，存在积分计费

- 搜索文档：https://uapis.cn/docs/api-reference/get-food-recipe
- 详情文档：https://uapis.cn/docs/api-reference/get-food-recipe-detail
- 控制台：https://uapis.cn/console
- 搜索：GET https://uapis.cn/api/v1/food/recipe?keyword=中文菜名
- 详情：GET https://uapis.cn/api/v1/food/recipe/detail?id=搜索返回的原始ID
- 实测番茄炒蛋、红烧肉、宫保鸡丁，各返回20条搜索结果。每组取首条详情：15步/15图、8步/8图、10步/10图，含用量清单。
- 文档指定的下厨房样例 xcf:104493058：6项食材、14步/14图。成品、首步、末步均通过HTTPS验证HTTP 200；成品640×520，步骤800×600；已目视检查首步原料准备照片。
- 文档声称搜索ID带来源前缀，实测搜索返回数字ID；将返回ID原样传入详情可用，不能自行补前缀。
- 搜索首条结果的豆果图片是HTTP。原始HTTP成品图实测能打开；直接换成HTTPS会发生证书域名不匹配，不能关闭证书检查来凑通过。若采用该源，应让服务端从原始合法公开图片URL获取图片，再以自己的HTTPS图片服务提供给前端。
- 搜索文档标1积分/次、详情3积分/次，访客有免费积分。官网没有在核查页面给出明确的可持续免费配额，因此归类为免费测试额度，不称作永久免费接口。

## 其余排除项

- 澄曜 api.ruseo.cn/api/caipu：实际HTTP 200，但业务data.error=unsupported content type，未返回可用菜谱。
- 万维易源：注册后提供免费档，但页面声明「仅供交流学习」，不能当作已确认可正式发布的内容授权。
